# Point Blank Password Changer

Website untuk mengelola dan mengganti password akun **Point Blank** secara aman.  
Cocok untuk dipakai di warnet, private server, atau sistem manajemen akun internal.

> ⚠️ **Disclaimer**  
> Proyek ini tidak berafiliasi dengan developer resmi Point Blank.  
> Gunakan hanya untuk kebutuhan legal, akun sendiri, atau server yang memang jadi tanggung jawab kamu.

---

## ✨ Fitur

- 🧾 **Satu halaman saja**  
  Tidak ada login, tidak ada dashboard, hanya satu form sederhana untuk ganti password.

- 🔍 **Validasi akun otomatis**  
  Ketika pengguna mengisi username:
  - Sistem mengecek ke database game.
  - Jika akun tidak ditemukan → menampilkan pesan error yang jelas.
  - Jika akun ada → proses ganti password dilanjutkan.

- 🔐 **Form ganti password**  
  - Input: username / login ID  
  - Input: password lama  
  - Input: password baru  
  - Validasi dasar: field wajib diisi, password lama dan password baru harus berbeda, dll.

- 📩 **Feedback yang jelas**  
  - Pesan berhasil ketika password berhasil diganti.
  - Pesan gagal saat akun tidak ditemukan atau validasi tidak terpenuhi.

- 📱 **Tampilan simpel & responsif**  
  Desain minimalis, mudah dipakai oleh pengguna non-teknis.
